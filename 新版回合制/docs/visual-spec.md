> 版本 v1.0 ｜ 负责人：林绘澄（美术总监）｜ 依据：`03-回合制玩法设计.md`
> 本文是「新版回合制」玩法所有美术产出的唯一视觉规格源，代码组据此落地 SVG/CSS。
> 硬约束：纯静态零依赖、双击离线可玩、无外部 URL 图片/字体/CDN、全部内联 SVG + CSS、不复制 BG3 原图（神似不复制）。

## 0. 一句话视觉基调

**问答玩法是「白天的手账」，回合制是「夜晚的桌游」。**

浅色手账风负责「看懂 TA 的内心」；回合制深色冒险风负责「骰子说了算的闯关」。两套主题在同一站内并存，用独立作用域隔离，互不污染。回合制整体 = **深夜色底 + 象牙白金骰子 + 像素风小队 + 梗图调侃情绪**，介于「可爱」与「调侃」的中间线，绝不滑向恐怖或廉价页游。

## 1. CSS 设计 Token（深色主题，集中管理）

> 关键决策：深色主题**不覆盖**旧版 `:root`，而是挂载在战斗容器作用域内，用一套 `--nx-*`（新版 New eXperience）前缀变量，避免与旧版 `--purple/--pink/--blue` 冲突。战斗页建议包在 `<div class="combat" data-theme="dark">` 或 `body[data-mode="combat"]` 下。

```css
/* ===== 深色主题总控（置于 .combat 或 body[data-mode="combat"] 作用域） ===== */
.combat {
  /* 底 / 面 / 文字 */
  --nx-bg:        #151221;   /* 全局深夜色底 */
  --nx-bg-2:      #1C1830;   /* 次级底 */
  --nx-card:      #241F3A;   /* 卡片 / 面板 */
  --nx-card-hi:   #2E2747;   /* 高亮面板 */
  --nx-line:      #3A3357;   /* 描边 */
  --nx-ink:       #EFEAF9;   /* 主文字（浅） */
  --nx-ink-soft:  #B7AECF;   /* 次级文字 */
  --nx-ink-faint: #7A719A;   /* 灰显 / 禁用 */

  /* 骰子（象牙白 + 金边，全局核心质感） */
  --nx-ivory:     #F4E9D3;
  --nx-ivory-shade:#D9C9A8;
  --nx-ivory-edge:#B9A67F;
  --nx-gold:      #D4AF6A;   /* 金边 */
  --nx-gold-hi:   #F0D48A;   /* 亮金高光 */

  /* 语义色（结算 / 特效 / HUD 统一） */
  --nx-prop:      #8E7CC3;   /* 主角属性紫（沿用旧版 --purple 色值） */
  --nx-skill:     #D4AF6A;   /* 技能金 */
  --nx-crit:      #FF9E3D;   /* 暴击橙 */
  --nx-crit-hi:   #FFC46B;
  --nx-fail:      #E5484D;   /* 失败红 / 大失败 */
  --nx-hp:        #FF7A45;   /* 血条橙红 */
  --nx-hp-deep:   #D0342C;

  /* 三关场景氛围色（见第 3 节） */
  --nx-s1-glow:   #7FE0D0;   /* 第1关手机荧光青 */
  --nx-s2-glow:   #B8C7E0;   /* 第2关投影冷白 */
  --nx-s3-glow:   #FFD9A0;   /* 第3关台灯暖光 */

  /* 半径 / 缓动（沿用旧版手感，保证两玩法操作一致） */
  --nx-r-sm: 12px;
  --nx-r-md: 18px;
  --nx-r-lg: 26px;
  --nx-r-pill: 999px;
  --nx-ease: cubic-bezier(.22,.8,.32,1);
}
```

**落地建议**：
1. 战斗页字体沿用旧版系统字体栈（无外部字体，见 `css/style.css` 的 `body` font-family）。
2. 阴影全部用「深色环境阴影」：`0 8px 24px rgba(8,6,20,.5)`，不要用旧版紫灰阴影（旧版阴影在深底上发灰）。
3. 像素风一律加 `image-rendering: pixelated;`；SVG 像素块加 `shape-rendering: crispEdges;`，防止浏览器抗锯齿糊边。

## 2. 整体视觉基调（九节精简版）

1. **视觉锚点**：深色桌游夜 —— BG3 的「掷骰闯关仪式感」× 手账的「象牙白金温柔质」。
2. **风格参照**：BG3 的 UI 面板质感（羊皮纸+金属边）→ 降饱和、卡通化；像素风小队致敬 CRPG 立绘小人；骰子走「温润象牙 + 描金」而非 BG3 的冷灰金属。
3. **配色**：深夜底色上，只允许「象牙 / 金 / 紫 / 橙 / 红 / 三关各自一个氛围光」这少数高饱和色出场，其余全部压灰，保证焦点。
4. **构图**：移动端竖屏 520px 单栏；上「场景 + BOSS」、中「结算/骰子」、下「队伍 + 操作」。骰子永远在视觉重心。
5. **角色视觉语言**：BOSS = 像素立绘 + 梗图气质；小队 = 像素小人（主角高亮、队友退后）。
6. **环境视觉语言**：每关一个专属氛围光 + 2-3 个漂浮粒子元素，营造「沉浸但不干扰」。
7. **UI 视觉语言**：面板圆角 + 细金边 + 象牙内衬，深色半透明玻璃拟态（`backdrop-filter: blur` 可用但需降级兜底）。
8. **动画原则**：掷骰是全场戏眼，动画最长最重；其余过渡 ≤ 200ms，尊重 `prefers-reduced-motion`。
9. **预算与命名**：全内联 SVG，无位图；命名前缀 `nx-`，见第 12 节资产清单。

## 3. 深色副本场景（三关）

### 通用场景结构（三层）
```
.scene              ← 场景容器，position:relative，overflow:hidden
  .scene-base       ← 纯色/渐变底
  .scene-glow       ← 氛围光晕（radial-gradient + blur 伪元素）
  .scene-particles  ← 漂浮粒子（多个小 DOM 或伪元素，CSS 动画）
  .scene-boss       ← BOSS 像素立绘层（绝对定位居中）
```

## 4. BOSS 像素立绘规格

### 通用规则
- **网格**：16×16（逻辑像素），渲染时放大到 **96×96 px**（×6）或 128×128（×8），放大必须 `image-rendering: pixelated`。
- **实现**：主推 **SVG `<rect>` 拼像素**（每个像素一个 1×1 rect，`viewBox="0 0 16 16"`，`shape-rendering: crispEdges`），便于用 CSS 类名整体换色做「吃痛/气势」状态；box-shadow 拼像素作为降级方案。
- **三种状态**（每个 BOSS 必有）：`normal` 正常 / `hurt` 吃痛 / `charge` 气势上升。
- **状态切换实现**：同一 sprite，用 CSS 类切换（`.boss.state-hurt .boss-pixel{...}` 换 `fill`，或整块 `filter: hue-rotate/sepia` 保底），外加状态专属的小挂件（汗滴 / 怒符 / 辉光）。
- 下方 ASCII 图为**权威参考骨架**，落位允许在保持配色与状态语义前提下微调 ±1px。

## 5. 类 BG3 的 d20 骰子规格

### 5.1 SVG 结构（20 面体正面视角的多边形拼贴）

采用「正三角形朝上 + 内部四等分」的经典 d20 平视图标，读起来就是一个「顶点朝上的二十面体」。`viewBox="0 0 200 180"`。

```
外层大正三角形（d20 轮廓，顶点朝上）
  A(100,10)  ← 顶
  B(20,170)  ← 左下
  C(180,170) ← 右下
内部中线三点（各边中点，构成倒三角）
  L(60,90)    ← 左边中点
  R(140,90)   ← 右边中点
  Bm(100,170) ← 底边中点
四块拼贴：
  1) 中央倒三角（= 朝玩家的「上」面，放数字）：(60,90)(140,90)(100,170)
  2) 顶部小三角：(100,10)(60,90)(140,90)
  3) 左下三角：(60,90)(20,170)(100,170)
  4) 右下三角：(140,90)(100,170)(180,170)
```

SVG 骨架（可复制）：
```svg
<svg class="d20" viewBox="0 0 200 180" shape-rendering="crispEdges">
  <g class="d20-body">
    <!-- 三块环绕面（压暗，营造体积） -->
    <polygon points="100,10 60,90 140,90"  class="face side" />
    <polygon points="60,90 20,170 100,170" class="face side" />
    <polygon points="140,90 100,170 180,170" class="face side" />
    <!-- 中央上表面（数字所在，象牙最亮） -->
    <polygon points="60,90 140,90 100,170" class="face up" />
    <!-- 金边（描边统一加在最上层，或用 stroke） -->
  </g>
  <text class="d20-num" x="100" y="146" text-anchor="middle">12</text>
</svg>
```

### 5.2 质感与配色
| 面 | 填充 | 描边 |
|---|---|---|
| 中央上表面 `.up` | `--nx-ivory` 象牙白，顶部加一层 `linear-gradient(#FFFDF6 → #E9DCC0)` | `--nx-gold` 2px |
| 三块环绕面 `.side` | `--nx-ivory-shade` 象牙暗部（`#D9C9A8` 到 `#C9B894` 渐变） | `--nx-gold` 1.5px |
| 数字 `.d20-num` | 默认 `--nx-ink`（深紫灰） | — |

- 金边质感：外层再加一个 `drop-shadow(0 0 6px rgba(212,175,106,.35))`，边缘可用 1px 亮金 `#F0D48A` 高光描边叠在暗金上，形成「描金」。
- 数字字号约 44px、`font-weight:700`，居中在中央三角内。

### 5.3 数字面状态
| 面值 | 表现 |
|---|---|
| 普通 2–17 | 象牙面 + 深紫灰数字，无额外高亮 |
| 暴击 18 / 19 / 20 | 数字变橙金 `--nx-crit`，中央面加 `radial-gradient` 橙金光晕 + `drop-shadow(0 0 14px rgba(255,158,61,.6))` |
| 大失败 1 | 数字变红 `--nx-fail`，中央面加红光晕 + 裂痕（见第 9 节） |

> 可访问性：暴击/大失败**不能只靠颜色**区分，必须同时出文字标签「暴击!」「大失败」+ 图标（见第 11 节）。

### 5.4 掷骰动画关键帧（戏眼，最重）
总时长约 **1.1–1.3s**，`cubic-bezier(.22,.8,.32,1)`，四段：

```
0%   抛落   translateY(-180px) scale(.9) rotate(-12deg) opacity 0 → 1
        （向上抛出，ease-out）
35%  旋转   3D 旋转：rotateX(720deg) rotateY(360deg) 快速翻滚，
        中间穿插 2–3 个随机数字面（用 JS 快速换 .d20-num 文本）
70%  弹跳   translateY(0) scaleY(.82) → scaleY(1) 两次小回弹
         （模拟骰子砸地 squash & stretch）
100% 定格   最终数字 + 结果特效（暴击橙光柱 / 大失败裂痕，见第 9 节）
```

- 旋转段用 `transform-style: preserve-3d` + `perspective` 包裹，或简化成 `rotate()` 2D + 数字快速切换（推荐后者，零依赖更稳）。
- 结果揭晓时骰子整体 `scale(1.06)` 再回落，制造「顿一下」的确认感。

## 6. 像素风队伍小人规格

### 通用规则
- **网格**：16×16（逻辑像素），放大到 **64×64 px**（×4）渲染，`image-rendering: pixelated`。
- **站位**（移动端横排一行，从左到右 4 格）：队友 A、队友 B、**主角（居中靠前）**、队友 C。
  - 主角：`transform: scale(1.15) translateY(-4px)` 靠前 + 底部金色地标环 + 外发光高亮。
  - 队友：`scale(.9)` 靠后 + `filter: saturate(.85)` 略褪，弱化存在感。
- **配色**：每角色 3 色（主色 / 暗部 / 高光）+ 统一 1px 深描边底色 `#1A1526`，与 BOSS 区分（小队更亮、更小、更暖）。
- **选中状态**：底部亮起象牙金地标环（`border:2px solid var(--nx-gold)` 的小椭圆），小人上浮 4px，外发光 `drop-shadow(0 0 6px #D4AF6A)`；被选中的「技能已用」小人整体 `filter: grayscale(.5) opacity(.5)` 并盖一个「CD」小锁图标。

## 8. 鉴定结算卡规格

结算卡是「掷骰 + 判定」的说明面板，位于骰子下方，深色玻璃拟态卡片（`background: rgba(36,31,58,.9); border:1px solid #3A3357; backdrop-filter:blur(6px)`）。

### 8.1 结构（自上而下）
```
┌─────────────────────────────┐
│ 鉴定类型：共情        [DC 12] │  ← 类型名 + DC 徽章

│ 主角属性修正(紫)  +2          │
│ 技能加成(金)     +3（1d4）    │
│ ───────────────────────────  │

└─────────────────────────────┘
```

### 8.2 配色
| 标签 | 颜色 token | 值 |

## 9. 特效规格

### 9.1 暴击（18–20，金色光柱 + 粒子爆闪 + 镜头微震）
1. **金色光柱**：骰子下方升起一根垂直金色渐变光束（`linear-gradient(180deg, #FFC46B 0%, rgba(255,158,61,0) 100%)`，`mix-blend-mode: screen`），`scaleY(0→1)` 0.25s。
2. **粒子爆闪**：12–16 个金色小方块/圆点（CSS 生成），从骰子中心向四周 360° 放射，`translate` + `opacity 0`，0.5s 内散开并淡出。
3. **镜头微震**：`.scene` 容器 `transform: translate()` 做 4 次 ±3px 快速抖动（0.3s），`prefers-reduced-motion` 时禁用。
4. 追加一行大字「暴击! 双倍伤害」橙金，`popIn` 弹出。

### 9.2 大失败（自然 1，骰子裂开 + 熊猫摊手）
1. **骰子裂开**：骰子中央叠一层裂纹 SVG（2–3 条折线 `stroke:#E5484D`），从中心向外 `stroke-dashoffset` 画出裂纹；骰子 `scale(.96)` + 轻微抖动。
2. **熊猫摊手**：骰子旁弹出一个「熊猫摊手」表情（第 11 节 `#emoji-panda`），配梗文案「我也没办法.jpg」。
3. 红色暗角：场景四周 `radial-gradient` 红暗角一闪。
4. 追加提示「大失败，气势 +2」红字。

## 11. 可访问性与动效红线

1. **结论/状态不靠颜色单传**：成功/失败、暴击/大失败、气势满层，一律配文字标签 + 图标（✓/✗/!）。
2. **对比度**：深底 `#151221` 上，正文文字不得低于 `#B7AECF`（约 7:1）；灰显文字 `#7A719A` 只用于装饰性信息，不承载关键判断。
3. **色盲友好**：暴击（橙）与大失败（红）同时给「数字符号」差异——暴击数字旁加 `✦`，大失败数字旁加 `✗`。
4. **`prefers-reduced-motion: reduce`**：掷骰旋转、镜头微震、粒子爆闪全部退化为「数字直接定格 + 一个轻淡入」，去掉位移/旋转/抖动。
5. **触控目标**：按钮/选项 ≥ 44×44px 命中区；队伍小人可点击区外扩 6px。
6. **像素缩放**：所有 `image-rendering: pixelated` 不得作用于文字（文字走系统抗锯齿），只作用于像素 sprite 与骰子。

## 13. 待确认项与风险

1. **小队小人具体造型**：16 角色各配一个像素头像装饰（卷王/拖延症等），造型细节与技能名尚待文案组补全——先按第 6 节「统一骨架 + 三色」落地，装饰后补。
2. **`backdrop-filter` 兼容性**：玻璃拟态在部分旧浏览器失效，需提供纯色兜底（不依赖 blur 也能读清）。
3. **骰子 3D 旋转**：建议用 2D `rotate` + 数字快速切换替代真 3D，零依赖下更稳；若工程组确认可用 `preserve-3d`，再升级。
4. **引擎/管线核对**：本文假设移动端 520px 单栏 + 系统字体栈，与旧版一致；若目标平台/视口有变，需与工程组（程基岩）核对渲染能力与性能预算（粒子数量、blur 层级）。
5. **侵权红线**：三关 BOSS 均为原创像素重绘，仅保留「骰子鉴定闯关」的玩法气质，未复刻 BG3 任何原画/UI 图形；表情均为原创简笔画，非平台版权表情。
